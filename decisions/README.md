# Decisions

- [ledger.csv](ledger.csv) / [ledger.json](ledger.json) – the decision ledger: one row per pain point, problem, opportunity, earlier idea, solution, written source, idea to discuss and not-recommended item, with Austin's call, status, what addresses it, the reason, and links up (toward transcripts) and down (toward solutions).
- [ledger-summary.md](ledger-summary.md) – counts per layer and status.
- [decisions-log.md](decisions-log.md) – Austin's decisions as logged on 9 Nov (calls on issues, audit answers, splits, bundles).
- [not-recommending.md](not-recommending.md) – not recommending, not included, dropped, idea to discuss, parked and rejected.
- Gaps and issues found while building the ledger: [../method/gaps-and-issues.md](../method/gaps-and-issues.md).

**Ledger statuses:** addressed = fixed by a DS; absorbed = merged into a DS built around another item; partly addressed = only part kept, or only "also helps"; parked / rejected = Austin's call (Park stays parked even if a DS also helps); dropped; idea to discuss; evidence only; not recommending.

Columns `links_up` / `links_down`: up points toward transcripts (pain point → `T-<interview>:<notion id>`), down toward solutions.
