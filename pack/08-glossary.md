# Glossary

Plain-English meanings for the terms used in this pack.

## Audit terms

| Term | Meaning |
| --- | --- |
| **Time saved** | Staff hours a solution removes each month, costed at $80/hr (Joe's figure). |
| **Capacity unlocked** | The extra MRR the same team could manage with the hours freed, without hiring: hours freed ÷ ~130 productive hours a month × MRR managed per account manager. Headroom, not guaranteed revenue. Time saved and capacity unlocked are the same hours counted two ways – never add them. |
| **$80/hr internal rate** | What an hour of staff time costs Aperitif (AUD). Used for all costing. Not the $150/hr charged to clients. |
| **Pain point (e.g. SD-PP04)** | One specific frustration someone described. The letters say whose interview it came from (SD = Shrishti Dokwal; KO = kick-off with Joe and Julia; MP = mid-point check-in). |
| **Problem (P-xx)** | A pattern of pain points with a shared cause, on the problem list. |
| **Cluster (C-xx)** | A group of similar pain points from different people. |
| **Root cause (RC-xx)** | The underlying reason behind several clusters. |
| **Opportunity (O-xx)** | A possible fix, merged from what people suggested in interviews. |
| **Earlier idea (EI-xx)** | One of Austin's ideas from before the interviews. |
| **Solution (DS-xx)** | A fix Austin has decided to recommend, written up with evidence, KPIs and value. |
| **Contradiction (X-xx)** | Where two interviews or documents disagree. |
| **WS-ZC-01** | Zach Chamberlain's written "AI suggestions" Google Doc – a written source, cited alongside the interviews. |
| **Raised by** | How many people raised something themselves, as "N staff + N leadership". Things Austin raised and someone agreed with don't count. |
| **Interviewer-raised** | Austin brought it up and the person agreed. Labelled, counted as corroboration only. |
| **Inferred / detected** | Worked out from what was said, not stated directly. Labelled. |
| **Solve now / later / Not in proposal / Reject** | The decision on each problem. Not in proposal = not solved here; each carries a short reason. |
| **Assumed / stated** | Stated = someone gave the figure. Assumed = an estimate. Most hours in this pack are assumed. |
| **KPI** | Key performance indicator – the number that shows whether a solution is working. |
| **OpEx** | Ongoing running cost (licences, subscriptions) rather than the one-off build cost. |
| **Build vs buy** | Whether to build a custom tool or pay for an existing one (SaaS). |
| **SaaS** | Software as a service – a tool you subscribe to rather than build. |

## Agency terms

| Term | Meaning |
| --- | --- |
| **Tier 1 / 2 / 3 / 4** | Client size and priority bands. Tier 1 = largest; they get weekly check-ins and QBRs. |
| **BAU** | Business as usual – the ongoing monthly work, as opposed to onboarding or projects. |
| **WIP** | Work-in-progress meeting where accounts are discussed. |
| **MRR** | Monthly recurring revenue – used in the career ladder as the revenue a person manages. |
| **QBR** | Quarterly business review – the deck presented to Tier 1 clients every quarter. |
| **6-month review** | The performance and strategy review deck for other clients. |
| **DLER** | MRR managed per person – how much monthly recurring revenue each person looks after (today ~$15.6K per person across 27 staff; live client board, 10 Nov). |
| **Retainer** | The fixed monthly fee a client pays. |
| **Churn** | Clients leaving. Churn rate = the share of clients lost in a year. |

## Paid media (PPC) terms

| Term | Meaning |
| --- | --- |
| **PPC** | Pay-per-click – paid ads on Google, Meta, Microsoft, LinkedIn, TikTok and others. Also called paid media or performance. |
| **Pacing** | Checking ad spend to date against the monthly budget, so a client doesn't overspend or underspend. |
| **Pacing sheet / pacing bot** | The Google Sheets that track pacing, and the "Tina" Slack bot that posts pacing updates on Monday, Wednesday and Friday. |
| **CPA** | Cost per acquisition – ad spend divided by the number of sales or sign-ups. |
| **CPL** | Cost per lead – ad spend divided by the number of leads. |
| **ROAS** | Return on ad spend – revenue earned for each dollar of ads. |
| **CTR** | Click-through rate – the share of people who see an ad and click it. |
| **SQR** | Search query report – checking which searches triggered the ads. |
| **PMax** | Google's Performance Max campaign type. |
| **Conversion tracking** | The tags that record when someone buys, calls or fills in a form after clicking an ad. |
| **Landing page** | The web page an ad sends people to. |
| **CRO** | Conversion rate optimisation – designing pages so more visitors become leads or sales. |
| **UGC-style ads** | Ads that look like user-generated content – a real person talking to camera. |

## SEO and content terms

| Term | Meaning |
| --- | --- |
| **SEO** | Search engine optimisation – helping clients get found on Google without paying for ads. |
| **GEO / AEO** | Generative engine optimisation / answer engine optimisation – getting clients cited in AI answers (ChatGPT, Google AI Overviews). Also called AI search visibility. |
| **Technical SEO** | The site-level work (speed, structure, errors) that lets Google read a website properly. |
| **Master SEO Document** | The per-client spreadsheet holding keyword mapping, the content plan, the link plan and the project plan. |
| **Content brief** | Instructions for a writer: the page, keywords, structure and links. |
| **Link building / backlinks** | Getting other websites to link to a client's site to lift its rankings. At Aperitif, mostly paid placements. |
| **Outreacher** | A person who finds and negotiates link placements on publisher sites. |
| **Publisher** | A website that hosts a paid link. |
| **Dofollow** | A link that passes ranking value to the client's site. A "nofollow" link doesn't. |
| **Anchor text** | The clickable words of a link. |
| **DR** | Domain Rating – Ahrefs' 0–100 score of a website's authority. |
| **Brand mention** | A website mentions a client by name without linking to them – a chance to ask for a free link. |
| **GA4** | Google Analytics 4 – website traffic and conversion data. |
| **Search Console** | Google's tool showing how a site performs in search. |

## AI and systems terms

| Term | Meaning |
| --- | --- |
| **AI Business Brain** | DS-15. The umbrella that connects the client brains, the AI playbook, the systems register and client health, so anyone can ask one place a question (through Slack). |
| **Client brain** | DS-04. One AI record per client that pulls together calls, emails, Slack, the work and the profile, so anyone can ask "what's going on with this client?". |
| **@oracle** | The working name for the Slack bot people would tag to ask the AI Business Brain a question. |
| **AI playbook / smart SOPs** | DS-02. One place for how Aperitif uses AI – rules, step-by-step guides, prompts and shared tools – that people can ask questions of. |
| **AI data rule** | The written rule (part of DS-02) on which AI tools are approved and what client data may go into them. Eight solutions need it first. |
| **SOP** | Standard operating procedure – a written step-by-step guide. |
| **Prompt** | The instructions typed into an AI tool. |
| **Claude skill / Claude Project** | A saved, reusable set of instructions and files in Claude, so a task is done the same way every time. |
| **Agent** | An AI tool that carries out a task with several steps on its own (for example, researching a new client). |
| **MCP** | A standard way of connecting an AI tool to another system, such as Ahrefs or Monday. |
| **API** | The connection one piece of software uses to read from or write to another. |
| **RBAC** | Role-based access control – people only see what their role allows (for example, commercial and HR detail limited to leadership). |
| **Runbook** | A short "what to do when it breaks" guide for a system (DS-10). |
| **Roomba** | The nickname for DS-06, the request sweeper that picks up stray requests from Slack, DMs and email and turns them into Monday tasks. |
| **Make / Zapier** | Automation tools that move data between systems. Make pushes HubSpot deals into Monday; Zapier runs Slack automations. |
| **OpenClaw** | Joe's personal AI agent set-up that runs Slack bots (including "Tina"). |
| **Supermetrics** | The tool that pulled ad data into Google Sheets. Its connector is failing, which broke the Meta pacing sheet. |
